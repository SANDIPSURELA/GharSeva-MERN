## Setup and remaining limits

SMTP needs permitted outbound connectivity and an authorized sender. Render Free blocks standard SMTP ports 25, 465 and 587; this adapter needs hosting that permits SMTP. No second provider was added.

Google/Apple require Firebase web configuration plus server service-account credentials and enabled providers/authorized domains. Apple additionally needs Developer Program configuration, Services ID, signing key/Team ID/Key ID, callback URL and private-relay sender configuration. See LOGIN-TWO-STEP-SETUP.md for exact variables and official references.
